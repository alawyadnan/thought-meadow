# Working on Thought Meadow

Read `PRODUCT_PRINCIPLES.md` before changing the native app's user experience. The owner has explicitly asked to preserve its simplicity and the clear, usable design praised in its first App Store review.

Favor small improvements to existing flows. Preserve immediate local note-taking, optional organization, user-controlled export, the existing visual identity and equal Arabic/English support. Keep the owner's future optional cloud-service plan separate from the free local core.

Validate the flows affected by a change. Use the existing native checks where relevant and describe simulator and physical-device results precisely. Do not report a check or release as complete unless it was verified.
