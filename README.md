# Jotmori

Free, open-source, local notes for iPhone, in English and Arabic.

Write notes, organize folders and tags, pin favorites, preview Markdown, use interactive checklists, and export backups through Files. Optional password encryption uses Apple's CryptoKit AES-256-GCM and CommonCrypto PBKDF2-SHA-256. No account, ads, analytics or server is required.

## Source and building

Download jotmori-ios-source.zip from this repository or the support site. It contains all native SwiftUI sources, the Xcode project, privacy manifest, MIT license, and native checks. Open Waraqa.xcodeproj and choose the Waraqa scheme; the internal project and bundle identifier retain the original development name for compatibility. iOS 17 or later, iPhone only.

The current release is 1.0.0 (2). It has been uploaded to Apple; App Store review and public availability are still pending. Sync, shared lists and subscriptions are not implemented. The app has not had an independent security audit.
